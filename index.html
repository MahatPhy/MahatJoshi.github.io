Spacenet

C++ · Python (pybind11) · SOFA · CMake · GitHub Actions

An astrodynamics library that computes a satellite's sun vector and, in the current iteration, its local magnetic field vector — the reference directions GNC software needs for pointing and attitude determination. Built under the mentorship of a control systems engineer, with an emphasis on independently cross-checked, tested numerical code rather than a single trusted implementation.

The sun vector is computed two separate ways — Vallado's classical four-frame rotation chain (precession, nutation, sidereal time, polar motion) and IAU-2006/2000A via the SOFA library — and checked against each other rather than assumed correct. A ~29-day periodic disagreement between the two chains turned out to trace back to an omitted lunar perturbation term, confirmed by lining the discrepancy up against the lunar month.

<0.01°Vallado vs. SOFA agreement
4–40 µsper reference-vector call
37+automated tests, CI on every push
3tiers: C++ core → bindings → Python

The iteration in progress adds IGRF-14 geomagnetic field evaluation — Schmidt-normalized associated Legendre polynomials, Gauss-coefficient conversion, and a dirty-flag caching model that only recomputes each tier (epoch, colatitude, vector) when its own inputs actually change — plus SGP4 orbit propagation to drive both vectors along a real satellite ground track.
